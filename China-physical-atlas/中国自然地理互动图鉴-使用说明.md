# 中国自然地理图鉴 · 互动地图使用说明

> 一个基于 **CesiumJS 1.147** 与 **天地图在线底图** 的三维中国自然地理教学网页。
> 包含三级阶梯、主要山脉走向、气候类型、干湿地区、温度带、四大盆地 / 四大高原 / 三大平原，以及可点击的知识卡片和动态图例。

---

## 一、快速开始

### 1.1 推荐：双击本地启动脚本

1. 确认电脑已安装 **Node.js 18 或更高版本**；
2. 双击项目根目录的 **启动地图.bat**；
3. 等待命令行窗口出现本地网址，浏览器会自动打开地图；
4. 使用期间**不要关闭命令行窗口**，关闭窗口后本地服务就会停止。

启动脚本实际执行的是：

~~~bat
node server.mjs
~~~

### 1.2 手动启动

在项目根目录打开终端，执行：

~~~bat
node server.mjs
~~~

浏览器会自动打开。若不想自动打开浏览器，可以使用：

~~~bat
node server.mjs --no-open
~~~

然后手动访问命令行提示的网址，例如：

~~~text
http://127.0.0.1:8123/
~~~

### 1.3 为什么建议用本地网页服务打开

天地图密钥是“**浏览器端**”类型，会校验网页访问来源。如果直接双击 HTML 文件（地址栏是 <code>file://</code>），请求可能被拒绝并出现 403。

使用 <code>server.mjs</code> 打开后，地址是 <code>http://127.0.0.1:8123/</code>，底图请求带有正常的网页来源，可以避免这一类问题。

页面在检测到 <code>file://</code> 时也会自动显示一条提醒。

## 二、界面与操作

| 区域 | 功能 |
| --- | --- |
| 左侧竖排按钮 | 鼠标靠近网页最左缘自动展开专题栏，离开后自动收回 |
| 左侧图钉 | 把专题栏固定在屏幕上，方便连续切换；再点一次取消固定 |
| 专题按钮 01–06 | 独立开启 / 关闭六个专题；默认支持同时叠加，多个专题的图例会在左下角逐项排列 |
| 左下角图例 | 随当前专题动态刷新，颜色、线型和降水 / 海拔说明都来自配置 |
| 右下角叠层图标 | 点击展开底图选择（矢量 / 遥感 / 地形）；面板底部可开关当前底图注记，遥感底图下显示为“影像注记” |
| 右上角指南针 | 显示当前方位；点击可让相机回正北 |
| 右上角 + / − | 按固定倍率放大 / 缩小地图 |
| 地图上滚轮 | 以较慢的平滑倍率缩放，最大 6.18% / 滚轮格（默认值） |
| 鼠标经纬度 | 页面底部中央实时显示 WGS 84 经纬度 |
| 比例尺 | 页面底部右侧，按当前相机视野动态计算 |
| 知识卡片 | 点击地图上的专题色块、山脉名称或阶梯分界线弹出 |
| 底部作者 / 版权 | 作者、天地图来源、Cesium 版权入口 |

### 键盘快捷键

| 按键 | 功能 |
| --- | --- |
| <code>1</code> 至 <code>6</code> | 开启 / 关闭对应专题 |
| <code>0</code> | 隐藏全部专题 |
| <code>H</code> | 回到中国全国视角 |
| <code>Esc</code> | 关闭知识卡片 / 底图面板 / 侧栏 |

### 交互细节

- 地图默认以正上方俯瞰中国全境，俯仰角约为 −90°，北向朝上。
- 地图鼠标滚轮使用自定义倍率，不会因为连续滚动而突然“钻”到底图下面。
- 相机高度被限制在约 6.5 千米至 16000 千米之间；靠近地表时会停止继续放大。
- 主要山脉在总览时只显示重点名称，缩近到约 3600 千米以内会显示其余山脉名称。
- 山川走向用不同颜色表示，箭头方向为数据中折线点的方向，仅作教学示意。

## 四、开发者配置指南

### 4.1 天地图密钥

密钥位于 <code>assets/app.js</code> 的配置区：

~~~js
var CONFIG = {
  TIANDITU_KEY: '67202ad0231a8193b8cdda3816077687',
  // ...
};
~~~

更换步骤：

1. 登录天地图开发者平台，确认密钥类型为“**浏览器端**”；
2. 在密钥的域名白名单中配置实际访问域名；本地调试通常包含 <code>127.0.0.1</code> / <code>localhost</code>；
3. 替换 <code>TIANDITU_KEY</code> 后刷新页面；
4. 不要在公开网站上直接复用别人的密钥，也不要把服务端密钥写进前端。

> 密钥是前端可见的。天地图浏览器密钥本身设计用于浏览器，但应通过域名白名单和配额管理限制使用范围。

### 4.2 初始视角、缩放与默认状态

全部位于 <code>assets/app.js</code> 顶部 <code>CONFIG</code>：

| 配置项 | 说明 |
| --- | --- |
| <code>INITIAL_RECT</code> | 初始视野的经纬度矩形；修改 west / south / east / north 可改变初始取景 |
| <code>MIN_CAMERA_HEIGHT</code> | 相机最低高度，防止放大穿透底图 |
| <code>MAX_CAMERA_HEIGHT</code> | 相机最高高度，防止缩得太远 |
| <code>ZOOM_BUTTON_FACTOR</code> | 加号 / 减号按钮每次的固定倍率 |
| <code>WHEEL_ZOOM_RATE</code> | 滚轮灵敏度，越小越慢；默认每 100 deltaY 约缩放 6% |
| <code>DEFAULT_THEME</code> | 初始专题，可选 steps / mountains / climate / drywet / landforms / temperature |
| <code>DEFAULT_BASE</code> | 初始底图，可选 vector / imagery / terrain |
| <code>ENABLE_MULTI_THEME</code> | 默认 true，可同时叠加多个专题；改为 false 则启用“开启新专题时收起旧专题”的单专题模式 |

初始镜头在 <code>setInitialView</code> 中设置，采用“矩形区域取景”，因此不同屏幕比例也能看到中国全境。

### 4.3 修改专题文案、图例和知识卡片

打开 <code>assets/thematic-meta.js</code>，每个专题的结构大致如下：

~~~js
climate: {
  id: 'climate',
  index: '03',
  name: '气候类型',
  accent: '#E3B76E',
  legendTitle: '中国气候类型分布',
  fillAlpha: 0.46,
  labelFont: '600 13px "Microsoft YaHei", sans-serif',
  legend: [
    { type: 'fill', color: '#DB7969', label: '热带季风气候', note: '全年高温' }
  ],
  tip: '点击不同气候区，查看气温、降水、植被与农业特征。',
  regions: {
    tropical: {
      name: '热带季风气候',
      color: '#DB7969',
      labelPos: [109.8, 19.3],
      tag: '气候类型 · 低纬季风',
      lead: '……',
      highlight: '全年高温 · 旱雨两季',
      facts: [['年均气温', '20℃ 以上']],
      note: '……'
    }
  }
}
~~~

字段含义：

| 字段 | 含义 |
| --- | --- |
| <code>name</code> | 侧栏 / 图例 / 标签上显示的名称 |
| <code>color</code> | 地图填充色、标签底色（建议和图例颜色一致） |
| <code>labelPos</code> | 标签的经纬度；设为 null 则不显示文本标签 |
| <code>extraLabels</code> | 可选，额外标签位置数组，例如 <code>[[100.8, 22.0]]</code>；适用于跨多个不相连区域的大分区 |
| <code>tag</code> | 卡片顶部的小分类文字 |
| <code>lead</code> | 卡片简介 |
| <code>highlight</code> | 卡片中的重点提示条，可留空 |
| <code>facts</code> | 卡片属性表，形式为 [标签, 内容] |
| <code>note</code> | “知识延伸”段落 |

修改时注意：

- <code>legend</code> 里的颜色和 <code>regions</code> 里同名区域的颜色分别用于图例和地图，最好保持一致；
- <code>regions</code> 的键名必须与 <code>assets/thematic-data.js</code> 中 <code>groups.climate</code> 的键名一致；
- 如果只想改文字，改完直接刷新页面即可，不需要重新生成数据。

### 4.4 修改山脉与走向

山脉数据在 <code>assets/thematic-meta.js</code> 的 <code>MOUNTAIN_ITEMS</code>：

~~~js
{
  id: 'qinling',
  name: '秦岭',
  dir: 'EW',
  coords: [[103.8,34.4],[106.0,33.9],[110.0,33.6],[111.8,33.7]],
  labelPos: [108.1,34.35],
  lead: '……',
  highlight: '我国1月0℃等温线',
  facts: [['走向','东西走向']],
  note: '……'
}
~~~

- <code>dir</code> 可选：<code>EW</code> 东西、<code>NE_SW</code> 东北—西南、<code>NS</code> 南北、<code>NW_SE</code> 西北—东南；
- <code>coords</code> 是折线点，点的排列方向也会决定箭头指向；
- 增加一条山脉时，复制一个对象、修改 id / name / coords / labelPos 即可，图例会自动加入；
- 地图上的重点名称由 <code>app.js</code> 中 <code>MAJOR_MOUNTAINS</code> 控制；不在其中的山脉名称会在缩近后显示。

### 4.5 修改专题区划多边形（需要重新生成数据）

**生成后的 <code>assets/thematic-data.js</code> 是自动生成文件，请不要直接手改坐标。**

生成流程：

1. 修改 <code>scripts/build_thematic_data.mjs</code> 中的教学示意多边形，例如 <code>stepBoundary12</code>、<code>stepBoundary23</code>、<code>climateShapes</code>、<code>dryWetShapes</code>、<code>temperatureShapes</code>、<code>landformShapes</code>；
2. 安装只在生成数据时需要的裁剪库：

~~~bat
npm install --prefix .build/deps polygon-clipping@0.15.7
~~~

3. 运行：

~~~bat
node scripts/build_thematic_data.mjs
~~~

4. 脚本会：

   - 读取 <code>data/china-provinces.geojson</code>；
   - 合并中国轮廓；
   - 用多边形裁剪使专题区不会画到国界之外；
   - 用 Douglas–Peucker 算法简化坐标；
   - 用 26 个关键城市坐标校验三级阶梯、气候类型、温度带和干湿区的归属，再用 30 个地形区关键点校验四大高原、四大盆地、三大平原的点位，并输出 PASS / FAIL 检查表；
   - 输出 <code>assets/thematic-data.js</code>。

校验城市及期望归属写在 <code>scripts/build_thematic_data.mjs</code> 的 <code>ANCHOR_CHECKS</code> 中，包括拉萨、西宁、成都、北京、石家庄、太原、武汉、广州、海口、乌鲁木齐、喀什等；其中干湿区期望值在 <code>DRY_WET_ANCHOR_EXPECT</code> 中补充。地形区校验写在 <code>LANDFORM_CHECKS</code> 中，采用 <code>include</code> / <code>exclude</code> 处理“柴达木盆地嵌套在青藏高原内”这类允许重叠的关系。修改边界后，请先查看构建日志中的归属检查，再去浏览器验收。

若关键城市或地形区关键点检查出现 FAIL，构建脚本会停止输出，避免把错误坐标写进页面；请先修正多边形或更新校验点。

地形区边界按教材常用范围绘制，属于教学示意：青藏高原复用第一阶梯轮廓，东北平原包含三江平原，柴达木盆地允许嵌套在青藏高原内。

脚本使用“教学示意多边形 + 中国轮廓裁剪”的方式。它**不是**官方自然地理区划，不应被用于行政、权属或工程用途。

区域名称和卡片文案仍然在 <code>thematic-meta.js</code> 中维护；重新生成几何不会覆盖文案文件。

### 4.6 增加 / 修改底图

底图定义在 <code>assets/app.js</code> 的 <code>BASEMAP_DEFS</code>：

~~~js
var BASEMAP_DEFS = {
  vector:  { name: '矢量底图', base: 'vec', labels: 'cva', short: '省界 · 地名 · 道路' },
  imagery: { name: '遥感底图', base: 'img', labels: 'cia', short: '卫星影像 · 地表纹理' },
  terrain: { name: '地形底图', base: 'ter', labels: 'cta', short: '地势晕渲 · 山脉起伏' }
};
~~~

天地图 WMTS 地址在 <code>createTiandituProvider()</code> 中拼接：

~~~js
https://t{s}.tianditu.gov.cn/<layer>_w/wmts?tk=<key>
~~~

若增加第四种底图，需同时：

1. 在 <code>BASEMAP_DEFS</code> 添加定义；
2. 在 <code>中国地理互动地图.html</code> 的“选择底图”面板中增加对应按钮（<code>data-base</code>）；
3. 在 <code>assets/style.css</code> 中按需增加缩略图样式。

底图面板底部的“影像注记 / 矢量注记 / 地形注记”共用同一套注记开关：它控制当前底图的 <code>labels</code> 图层（影像为 <code>cia</code>，矢量为 <code>cva</code>，地形为 <code>cta</code>）。默认开启，切换底图时保持当前开关状态。

### 4.7 修改颜色、字体和 UI 布局

打开 <code>assets/style.css</code>，优先修改顶部的 <code>:root</code> 变量：

~~~css
:root {
  --ink: #eef5f0;
  --jade: #8fd3b6;
  --night: #071119;
  --serif: "Songti SC", "STSong", "Noto Serif CJK SC", "SimSun", Georgia, serif;
  --sans: "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", "Segoe UI", sans-serif;
  --dock-height: 48px;
}
~~~

- 地图上的专题颜色主要在 <code>thematic-meta.js</code> 的 <code>color</code> / <code>legend</code> 中；
- 卡片、侧栏、按钮的 UI 颜色主要受 CSS 变量控制；
- 底部状态栏高度由 <code>--dock-height</code> 控制，其他浮层会相应定位；
- 响应式断点为 1100px、860px、600px、390px。

### 4.8 地图逻辑与代码分区

<code>assets/app.js</code> 内部按中文注释编号：

| 分区 | 内容 |
| --- | --- |
| 00 | 配置、底图名称、全局状态 |
| 01 | 页面启动、异常提示 |
| 02 | Cesium Viewer 初始化、海面特效关闭、相机控制器 |
| 03 | 天地图三套底图与异常监听 |
| 04 | 初始视角、滚轮 / 按钮缩放、指南针 |
| 05 | 经纬度、比例尺 |
| 06 | 专题图层绘制、山脉折线、虚线分界、标签 |
| 07 | 图例 DOM 生成 |
| 08 | 地图拾取、知识卡片 |
| 09 | 侧栏、底图面板、快捷键、提示 |
| 10 | 启动收尾、调试接口 |

其中：

- **海洋特效**：代码显式关闭 <code>globe.showWaterEffect</code>（存在时）、地面大气、天空大气、光照、雾效、太阳 / 月亮 / 星空，满足“不启用 Cesium 自带海洋特效”的要求；
- **防止穿透**：<code>MIN_CAMERA_HEIGHT</code> + <code>screenSpaceCameraController.minimumZoomDistance</code> + <code>enableCollisionDetection</code> 共同限制；
- **滚轮速度**：劫持 canvas 的 wheel 事件并用 <code>Math.exp(deltaY × WHEEL_ZOOM_RATE)</code> 计算倍率，同时移除 Cesium 默认 WHEEL 缩放类型，避免双重缩放；
- **显存/图形上下文恢复**：浏览器丢失 WebGL 上下文时会自动刷新一次；再次失败则给出明确的中文提示，不再无限重载。

页面初始化成功后，控制台可以使用：

~~~js

ChinaAtlas.setBase('imagery')
~~~

### 4.10 升级 CesiumJS

当前本地运行时是 **Cesium 1.147.0**。

升级步骤：

1. 下载官方 Cesium 发布包；
2. 用新版本 <code>Build/Cesium</code> 的内容整体替换 <code>vendor/cesium/</code>；
3. 保留 <code>vendor/cesium/LICENSE.md</code> 或新版许可证文件；
4. 在浏览器中重新检查底图、实体绘制、标签、WebGL 着色器和版权显示；
5. 如本地 Cesium 缺失，页面会尝试从 unpkg 加载 1.147.0 作为兜底，可同步修改 HTML 中的兜底版本号。

## 五、常见问题

### 5.1 页面打开了，但底图是黑的 / 空白

按顺序检查：

1. 地址是否为 <code>http://127.0.0.1:8123/</code>？直接双击 HTML 可能触发密钥来源限制；
2. 是否联网？可以打开天地图官网验证网络；
3. 天地图密钥是否仍然有效、是否配置了域名白名单；
4. 打开浏览器开发者工具 Network 面板，筛选 <code>tianditu.gov.cn</code>，检查是否返回 401 / 403；
5. 关闭其他大量占用网络的标签页后刷新。

### 5.2 提示“天地图底图请求被拒绝”

通常是访问来源或密钥类型问题：

- 确认密钥为“浏览器端”类型；
- 通过本地服务打开，而不是 <code>file://</code>；
- 确认当前域名在天地图密钥白名单中；
- 如更换了密钥，只改 <code>assets/app.js</code> 的 <code>TIANDITU_KEY</code>。

### 5.3 出现“图形上下文暂时中断 / 正在恢复图形显示”

这是浏览器 WebGL 上下文丢失，常见于切换显卡、驱动重置、显存压力过大或多标签页同时运行三维页面。页面会自动刷新一次尝试恢复；如果再次失败，请：

1. 关闭其他三维 / 游戏 / 视频网页；
2. 重启浏览器；
3. 在浏览器设置中开启硬件加速；
4. 更新显卡驱动。

### 5.4 怎么换端口？

<code>server.mjs</code> 默认从 8123 开始，如果端口被占用会自动向后尝试。

也可以：

~~~bat
set PORT=9000
node server.mjs
~~~

### 5.5 为什么总览时只看到部分山脉名称？

为了防止 25 条山脉名称在总览时挤在一起，<code>app.js</code> 用 <code>MAJOR_MOUNTAINS</code> 标记重点山脉。滚轮缩近到约 3600 千米以内，其余名称会自动出现。

### 5.6 如何增加某个专题的图例项？

在 <code>assets/thematic-meta.js</code> 对应专题的 <code>legend</code> 数组里增加一项：

~~~js
{ type: 'fill', color: '#8DB5DD', label: '新区域', note: '说明' }
~~~

- <code>type: 'fill'</code> 表示色块；
- <code>type: 'line'</code> 表示线条；
- 线条可加 <code>dashed: true</code> 或 <code>arrow: true</code>。

### 5.7 想离线使用完整底图可以吗？

当前底图直接请求天地图的在线 WMTS。Cesium 运行时已本地化，但底图仍需联网。

如果需要完全离线，需要另行部署天地图瓦片或合法的离线底图服务，并修改 <code>createTiandituProvider()</code> 的地址。请遵守天地图服务条款。

### 5.8 温度带的分类标准是什么？

温度带依据 ≥10℃ 活动积温划分：寒温带 < 1600℃、中温带 1600—3400℃、暖温带 3400—4500℃、亚热带 4500—8000℃、热带 > 8000℃。青藏高原区因海拔高、热量低，单独作为高寒气候区表示，不与纬度温度带混用。

### 5.9 多专题叠加怎么用？

页面默认启用多专题叠加（<code>CONFIG.ENABLE_MULTI_THEME = true</code>）。依次点击侧栏 01–06 的任意多个按钮，按钮会同时保持高亮，左下角图例按专题分节排列；再次点击某个按钮只关闭该专题。

- 推荐课堂使用时同时叠加 2–3 个专题；
- 六个专题全部打开时，标签会比较密集，可用“隐藏全部专题”或单独关闭某一层；
- 叠加多个专题后，图例内容较长，可在图例区域滚动查看；
- 若希望一次只显示一个专题，可将 <code>ENABLE_MULTI_THEME</code> 改为 <code>false</code>。

### 5.10 干湿地区是怎么划分的？

干湿地区按年降水量与蒸发量的对比划分：湿润区 > 800 毫米、半湿润区 400—800 毫米、半干旱区 200—400 毫米、干旱区 < 200 毫米。地图中的边界按教材常用分布简化：青藏高原主体、内蒙古高原和准噶尔盆地属于半干旱区；塔里木、柴达木、阿拉善等属于干旱区；四川盆地、云南南部和东部季风区属于湿润区；东北东部（三江平原、长白山一带）属于湿润区，东北中部属于半湿润区，呼和浩特一带属于半干旱区。

### 5.11 如何关闭天地图影像注记？

打开右下角底图面板，选择“遥感底图”，再关闭面板底部的“影像注记”开关即可只保留卫星影像。矢量/地形底图会显示对应的“矢量注记 / 地形注记”开关；默认开启，切换底图时保持当前状态。

### 5.12 地图卡顿怎么办？

可以在 <code>assets/app.js</code> 中：

- 降低 <code>resolutionScale</code>；
- 增大 <code>globe.maximumScreenSpaceError</code>；
- 减少同时开启的专题（默认支持叠加，建议 2–3 个；也可将 <code>ENABLE_MULTI_THEME</code> 改为 <code>false</code> 使用单专题模式）；
- 减少高密度专题的轮廓线数量。
